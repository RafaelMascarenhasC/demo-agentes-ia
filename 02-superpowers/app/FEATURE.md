# Feature da demo: prioridade nas tarefas (visível no site)

Ideia (curta e cheia de buracos de propósito, pra o superpowers ATACAR os requisitos):

> "Quero dar uma prioridade pra cada tarefa (alta/normal/baixa), escolher ao adicionar no site,
>  ver uma etiqueta colorida em cada tarefa e as pendentes ordenadas por prioridade."

Perguntas que o superpowers (na fase de **brainstorming/design**) provavelmente vai levantar (deixe ele levantar):
- Qual a prioridade padrão de uma tarefa nova?
- Empate de prioridade: mantém a ordem de inserção?
- Tarefas já feitas entram na ordenação?
- Prioridade inválida = erro ou vira padrão?

O código base do site está em `servidor.py` (web) e `tarefas.py` (lógica).
É esse ataque aos requisitos que diferencia o superpowers do "cru".
