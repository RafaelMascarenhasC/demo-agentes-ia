# Como rodar os testes deste projeto

- Rode SEMPRE com o unittest nativo, na pasta do projeto:
  `python3 -m unittest -v`
- NUNCA diga que passou sem antes ver a linha final `OK`.
- Se algum teste falhar, mostre a saída real e ache a causa-raiz antes de mexer no código.
